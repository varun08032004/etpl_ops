# C14: Marketplace & Trading
## Module 14.3: Cross-Border & Regulatory Arbitrage (3 lessons × 40min = 2h)

### Lesson 14.3.1: Cross-Border Carbon Trading — Article 6, CORSIA & Border Adjustments
**Lesson Code:** C14.3.1
**Duration:** 40 minutes
**Lesson Type:** document
**Tier:** professional

**Learning Objectives:**
1. Navigate Article 6.2 bilateral cooperation: authorization, corresponding adjustments, ITMOs (Bloom: Apply)
2. Navigate CORSIA compliance: eligible units, airline obligations, registry bridges (Bloom: Apply)
3. Analyze border carbon adjustments: CBAM, UK ETS linkage, import carbon pricing (Bloom: Analyze)

**Prerequisites:** C14.1.1, C14.1.2, C14.1.3

**Why This Matters:**
Carbon markets are inherently global — emissions anywhere affect climate everywhere. Cross-border trading (Article 6.2), aviation compliance (CORSIA), and border adjustments (CBAM) are the three pillars connecting domestic action to global integrity. Mastering these linkages lets you access global supply, meet international obligations, and anticipate regulatory convergence.

**Core Concept: Carbon Knows No Borders — But Rules Do**

### 14.3.1.1 Article 6.2 — Bilateral Cooperative Approaches

**Article 6.2 Architecture:**
```
Host Country (Seller)          Buying Country (Buyer)
┌─────────────────────┐        ┌─────────────────────┐
│  Mitigation Activity│        │  NDC Target         │
│  (Project/Program)  │        │  (Needs ITMOs)      │
│       │             │        │       │             │
│       ▼             │        │       ▼             │
│  Host Country       │        │  Buying Country     │
│  Authorization      │        │  Authorization      │
│  (LoA)              │        │       │             │
│       │             │        │       │             │
│       ▼             │        │       ▼             │
│  Corresponding      │        │  Corresponding      │
│  Adjustment         │◄───────►│  Adjustment         │
│  (NDC Adjustment)   │  ITMO   │  (NDC Adjustment)   │
└─────────────────────┘        └─────────────────────┘
```

**Key Requirements (Decision 2/CMA.3):**
| Requirement | Detail |
|-----------|--------|
| **Authorization** | Host Party issues Letter of Authorization (LoA) for each cooperative approach |
| **Corresponding Adjustment (CA)** | Mandatory for all ITMOs; seller deducts from NDC, buyer adds |
| **First Transfer** | Triggers CA; must be tracked in registry |
| **Reporting** | Annual; in Biennial Transparency Report (BTR) |
| **Authorization Format** | Standardized (Decision 2/CMA.3 Annex); includes: activity, sector, geography, vintage, method, volume, vintage, participating Parties |
| **Registry** | National registry ↔ Article 6 registry (international transaction log) |
| **Vintage** | Must be specified; typically year of mitigation outcome |
| **Metrics** | Tonnes CO2e; non-CO2 converted using GWP100 (AR6) |
| **Reporting** | Annual; in Biennial Transparency Report (BTR); Article 6 database |

### 14.3.1.2 Article 6.2 — Operational Workflow

**Pre-Trade (Project Development):**
```
1. Project Developer → Host Country DNA → Request LoA
2. Host Country DNA → Issues LoA (specifies: activity, volume, vintage, methodology, vintage)
3. Project Registers with Host Country Registry
4. Buyer Country DNA → Acknowledges LoA; prepares to receive ITMOs
```

**Trade Execution:**
```
1. Contract: ERPA/ITMO Purchase Agreement
   • Volume, Vintage, Price, Delivery Schedule
   • CA Mechanism: Automatic at first transfer (registry-level)
   • Authorization References: LoA numbers, dates, authorized entities
   
2. Execution:
   a) Seller initiates transfer in Host Registry
   b) Host Registry → Article 6 Registry (International Transaction Log)
   c) Buyer Registry receives ITMO
   e) Corresponding Adjustment: Host NDC - ITMO; Buyer NDC + ITMO
   
3. Post-Trade:
   - Annual Reporting (BTR)
   - Article 6 Database Update
   - Registry Reconciliation (National ↔ Article 6 Registry)
```

**India's Article 6.2 Readiness:**
| Element | Status |
|---------|--------|
| **DNA** | BEE (Bureau of Energy Efficiency) |
| **LoA Process** | Operational (BEE issues LoAs) |
| **Bilateral Agreements** | Japan (JCM), Sweden, Switzerland, Singapore, US (exploratory) |
| **Registry Bridge** | ICMS ↔ Article 6 Registry (under development) |
| **Corresponding Adjustment** | Methodology published (BEE); automation in progress |
| **CDM Transition** | ~300 CDM activities eligible for Art 6.4 transition |

### 14.3.1.3 CORSIA — Aviation Compliance via Carbon Markets

**CORSIA Overview:**
| Element | Detail |
|---------|--------|
| **Governance** | ICAO (International Civil Aviation Organization) |
| **Objective** | Carbon-neutral growth from 2020 baseline (2019 adjusted) |
| **Applicability** | International flights; airlines > 10,000 tCO2/yr |
| **Phases** | Pilot (2021-23), Phase 1 (2024-2026), Phase 2 (2027-2035) |
| **Eligible Units** | CORSIA-eligible programs (CDM post-2015, VCS, GS, ACR, ART) |
| **Eligibility Criteria (ICAO Assembly A40):** |
| - Program governance & transparency |
| - Additionality assessment |
| - Permanence safeguards |
| - MRV requirements |
| - No double counting (registry, cancellation) |
| - Sustainable development safeguards |

**Current Status:** Pilot phase complete; Phase 1 operational; Phase 2 (2027-2035) mandatory for all States.

**India Context:** Indian airlines (IndiGo, Air India, etc.) subject to CORSIA; DGCA implements; CCCs from ICMS can be used if CORSIA-eligible.

### 14.3.1.4 Professional Judgement Points
- **Vintage is everything:** 2021 vintage ≠ 2022 vintage for CORSIA eligibility
- **Article 6.2 ≠ Voluntary Market:** CA is mandatory; voluntary credits don't transfer
- **Host Country LoA:** Can take 60-120 days; start early
- **Corresponding Adjustment:** Automatic in registry if both sides integrated; manual otherwise
- **Vintage Rules:** CORSIA Phase 1 = 2021-2023 vintages; Phase 2 = 2021+

### Lesson 14.3.2: Border Carbon Adjustments — CBAM, Linkage & Trade Policy
**Lesson Code:** C14.3.2
**Duration:** 40 minutes
**Lesson Type:** document
**Tier:** professional

**Learning Objectives:**
1. Analyze the EU CBAM mechanism: scope, calculation, compliance, timeline (Bloom: Analyze)
2. Evaluate ETS linkage: price convergence, market integration, regulatory harmonization (Bloom: Analyze)
3. Assess trade implications: WTO compatibility, developing country concerns, leakage risk (Bloom: Evaluate)

**Prerequisites:** C14.1.1, C14.1.2, C14.3.1

**Why This Matters:**
Border Carbon Adjustments (BCAs) are the next frontier of carbon policy — extending domestic carbon pricing to imports to prevent leakage and level the playing field. The EU CBAM is the first major implementation; others (UK, Canada, US) are following. Understanding CBAM mechanics is essential for any carbon professional advising exporters, importers, or policymakers.

**Core Concept: BCAs Extend Domestic Carbon Price to the Border — Leveling the Global Playing Field**

### 14.3.2.1 EU CBAM — Mechanism Deep Dive

**CBAM Scope (Regulation (EU) 2023/956):**
| Sector | CN Codes (Indicative) | Coverage |
|----------|----------------------|----------|
| **Cement** | 2523 | Clinker, cement |
| **Iron & Steel** | 7201-7229 | Pig iron, ferro-alloys, steel products |
| **Aluminium** | 7601-7616 | Unwrought, alloys, scrap, articles |
| **Fertilizers** | 3102-3105 | Nitrogenous, phosphatic, potassic |
| **Hydrogen** | 2804 | Hydrogen |
| **Electricity** | 2716 | Electricity imports |

**Transition Phase (Oct 2023 - Dec 2025):**
| Requirement | Detail |
|-----------|--------|
| **Reporting Only** | Quarterly CBAM reports (emissions, embedded emissions, carbon price paid abroad) |
| **No Financial Obligation** | No certificates to buy/surrender yet |
| **Data Requirements** | Direct emissions; indirect (electricity); carbon price paid in origin |

**Definitive Period (Jan 2026+):**
| Requirement | Detail |
|-----------|--------|
| **CBAM Certificates** | Importers buy/surrender CBAM certificates = embedded emissions |
| **Price** | EU ETS weekly average price (minus carbon price paid in origin) |
| **Embedded Emissions** | Direct + Indirect (electricity) per CBAM methodology |
| **Verification** | Accredited verifier; CBAM declarant responsible |
| **Default Values** | If actual data unavailable: EU default values (conservative) |

**CBAM Certificate Mechanics:**
```
1. IMPORTER (CBAM Declarant) registers in CBAM Transitional Registry
2. PER IMPORT:
   a) Declare: Product, Quantity, Country of Origin, Installation
   b) Provide: Embedded Emissions (verified), Carbon Price Paid Abroad
   c) Calculate: CBAM Certificates = Embedded Emissions - Free Allowances - Carbon Price Paid
3. SURRENDER: Annual (by May 31 following calendar year)
4. COMPLIANCE: Customs release linked to CBAM certificate surrender
```

### 14.3.2.2 CBAM — Embedded Emissions Calculation

**Embedded Emissions = Direct + Indirect**
```
Embedded Emissions = Direct Emissions + Indirect Emissions (Electricity)
Direct = Process emissions (Scope 1) per installation
Indirect = Electricity Consumption × EF_grid (location-based)
```

**Default Values (If Actual Data Unavailable):**
| Sector | Default Direct (tCO2e/tonne) | Default Indirect (tCO2e/tonne) |
|--------|------------------------------|--------------------------------|
| **Cement** | 0.85 | 0.15 |
| **Iron & Steel** | 2.10 | 0.30 |
| **Aluminium** | 8.50 | 1.20 |
| **Fertilizers** | 1.50 | 0.40 |
| **Hydrogen** | 0.00 | 5.00 |
| **Electricity** | N/A | 0.45 (EU avg) |

**CBAM Certificate Price:**
```
Certificate Price = EU ETS Weekly Avg Price - Carbon Price Paid in Origin Country
Minimum = 0 (if origin carbon price ≥ EU ETS price)
```

### 14.3.2.2 ETS Linkage — Price Convergence & Market Integration

**Linkage Types:**
| Linkage Type | Mechanism | Example | Status |
|------------|-----------|--------|--------|
| **Direct (Two-Way)** | Mutual recognition; allowances fungible | EU ETS ↔ Swiss ETS (2020) | Operational |
| **One-Way Link** | A accepts B's allowances; B doesn't accept A's | California ↔ Quebec (partial) | Limited |
| **Indirect (Price Reference)** | A's price floor/ceiling references B's price | CBAM references EU ETS | Designing |
| **CBAM as De Facto Link** | Imports pay EU ETS price | EU CBAM | Transitional |

**Price Convergence Dynamics:**
```
Linked ETS → Price Convergence (Arbitrage)
Unlinked but CBAM → Import Price = Domestic Price + CBAM Cost
CBAM Cost = EU ETS Price - Origin Carbon Price
→ Origin Country Incentivized to Price Carbon (to keep revenue domestic)
```

### 14.3.2.3 Trade Implications — WTO, Developing Countries, Leakage

**WTO Compatibility Arguments:**
| Argument | Pro-CBAM | Anti-CBAM |
|----------|----------|-----------|
| **Art. XX (GATT)** | Environmental exception (b) / (g) | Discriminatory; disguised restriction |
| **National Treatment** | Applies equally to domestic/import | De facto discrimination (domestic free allowances) |
| **Carbon Leakage** | Prevents leakage; levels field | Shifts production; doesn't reduce global emissions |

**Developing Country Concerns:**
| Concern | CBAM Provision | Mitigation |
|----------|----------------|------------|
| **Cost Burden** | LDCs exempt (transition period) | Technical assistance fund |
| **Data/Verification Capacity** | Default values (conservative) | Capacity building fund |
| **Export Competitiveness** | CBAM cost = tariff equivalent | Transition period (2023-2025) |

**Carbon Leakage Risk — CBAM Impact:**
| Scenario | Leakage Risk | CBAM Effect |
|----------|--------------|-------------|
| **Full Auctioning + CBAM** | Low | High (price signal + border) |
| **Free Allocation + CBAM** | Medium | Medium (partial) |
| **No CBAM + Free Allocation** | High | None |

### 14.3.2.3 Professional Judgement Points
- **CBAM is a template:** UK, Canada, US, Australia designing similar — learn EU implementation
- **Data is king:** Embedded emissions verification is the bottleneck — invest in supplier data
- **Indirect emissions:** Electricity EF is the biggest uncertainty — push suppliers for actual data
- **Default values = Cost:** Conservative defaults = higher CBAM cost; invest in actual data
- **Strategic sourcing:** Shift sourcing to low-carbon origins; CBAM as procurement lever

### 14.3.2.3 Practical Exercise: CBAM Compliance Design
*Scenario:* An Indian steel exporter ships 50,000 tonnes of hot-rolled coil to EU annually. Plant: BF-BOF route; grid electricity; no on-site renewables. Current EU ETS price: €85/tCO2. Indian grid EF: 0.71 kgCO2/kWh.
*Tasks:*
1. Calculate embedded emissions (direct + indirect) per tonne
2. Estimate CBAM certificate cost/tonne (assume EU ETS €85/t)
3. Evaluate abatement options: (a) Green H2 injection, (b) Scrap-based EAF shift, (c) Renewable PPA
3. Design CBAM compliance workflow (data collection → verification → surrender)
*Time:* 45 min
*Deliverable:* CBAM Compliance Plan + Cost-Benefit Analysis
*Rubric:* Calculation accuracy (30%), regulatory accuracy (30%), strategic insight (40%)

**Knowledge Check:**
1. What products are in CBAM scope? (Cement, Iron & Steel, Aluminium, Fertilizers, Hydrogen, Electricity)
2. When does financial obligation start? (Jan 2026; transitional reporting Oct 2023)
3. How is "carbon price paid abroad" deducted? (Proof of explicit carbon price; not implicit policies)
4. What happens if embedded emissions data is unavailable? (EU default values — conservative)
